# Deteksi_Kematangan_Jeruk_JST
Proyek ini merupakan implementasi praktis dari mata kuliah Kecerdasan Buatan dan Pemrograman Perangkat Mobile yang juga menjadi topik tugas akhir skripsi saya. Fokus utama proyek ini adalah mengembangkan sistem objektif untuk mendeteksi tingkat kematangan buah jeruk menggunakan teknik pengolahan citra digital dan komputasi.
